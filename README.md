# Stuart Savage Career Portfolio

Create a new professional career portfolio website called “Stuart Savage Career Portfolio”. Use the Workspace Knowledge and the Stuart Career Profile and Stuart Portfolio Content skills as the source of truth.

Position Stuart for corporate leadership roles in operations, customer experience, service delivery and strategic project delivery. This must not advertise landscaping services. Historic SAVAGELDN work may appear only as evidence of leadership, logistics, commercial ownership and accountable delivery.

Build a polished, accessible, responsive single-page portfolio with:

- a strong hero and concise professional summary;

- core skills and capabilities;

- verified career experience;

- transferable project evidence;

- target role areas including transport and rail;

- contact links for email and LinkedIn;

- clear UK English throughout;

- semantic HTML, keyboard access, visible focus, strong contrast and reduced-motion support;

- useful SEO metadata and structured data.

Use an editorial, premium and human visual style with generous spacing and no generic AI imagery. Do not invent employers, dates, metrics, qualifications or achievements. Keep the project unpublished until I review it.
