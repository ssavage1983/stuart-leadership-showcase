# Purpose

Audit component quality, WCAG accessibility, visual design consistency, and copy standards across stuart-leadership-showcase.lovable.app.

# Verification Checklist

1. **Accessibility (WCAG):** Confirm semantic HTML5 elements, visible focus rings, aria-labels for buttons/interactive icons, and full keyboard tab navigation.
2. **Mobile Responsiveness:** Test mobile width (375px) to ensure zero horizontal scrolling and touch-friendly interactive targets.
3. **Copy & Localization:** Audit all UI text for strict UK English spelling (e.g. programme, modelling, organisation) and sentence case on buttons/headings.
4. **Data Integrity:** Guarantee no "Lorem ipsum" or generic placeholder text remains in production views.
